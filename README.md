# Weather API and Weather Data

The Visual Crossing Weather API provides developers with weather data for any programming language, application, or script. The Weather API provides fast, scalable access to historical weather, current conditions, and weather forecasts in easy-to-use JSON, CSV, and Excel formats.

See the [Visual Crossing Weather API](https://www.visualcrossing.com/weather-api/) for more information, documentation, sample code, and use cases.

To view weather data, download weather data, and build Weather API queries, visit the [Visual Crossing Weather Query Builder](https://www.visualcrossing.com/weather-query-builder/).

To sign up for a free Visual Crossing account, visit [Visual Crossing sign up](https://www.visualcrossing.com/sign-up/).

## Weather API

The Timeline Weather API is the primary REST API for retrieving historical weather, current conditions, and forecast data using a single consistent API.

[Timeline Weather API documentation](https://www.visualcrossing.com/resources/documentation/weather-api/timeline-weather-api/)

[Weather data element documentation](https://www.visualcrossing.com/resources/documentation/weather-data/weather-data-documentation/)

## Weather MCP Server

The Visual Crossing Weather MCP Server provides MCP-compatible AI assistants, agents, and development tools with direct access to Visual Crossing weather data through the Model Context Protocol (MCP).

The MCP server provides structured access to current conditions, weather forecasts, recent historical weather, and supported specialized weather elements. It can be used with MCP-compatible clients and agent frameworks without requiring a custom REST API integration.

[Visual Crossing MCP documentation](https://www.visualcrossing.com/resources/documentation/weather-api/visual-crossing-mcp-guide/)

MCP server endpoint:

`https://mcp.visualcrossing.com/VisualCrossingWebServices/rest/api/v1/mcp`

## Weather Maps API

The Visual Crossing Weather Maps API provides ready-to-use weather map tiles, static map images, and map legends for use in interactive maps, dashboards, reports, and other applications.

The API supports standard XYZ map tiles for libraries such as Leaflet, MapLibre, OpenLayers, Google Maps, and ESRI, along with stitched static weather map images and matching legends.

[Weather Maps API documentation](https://www.visualcrossing.com/resources/documentation/weather-api/weather-maps-api/)

[Weather Maps API integration samples](https://www.visualcrossing.com/resources/documentation/weather-api/weather-map-api-integration-samples/)

Weather data is sourced from [Visual Crossing Weather Data](https://www.visualcrossing.com/weather-data/).
